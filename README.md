# Web_Based_Quiz_System_
The Web Based Quiz System is a web-based platform designed to simplify quiz creation, management, and participation. It provides separate dashboards for students and administrators, enabling seamless interaction, performance tracking, and automated result generation.

Features:
 
For Students-
Register and log in securely
Access available quizzes by subject
Attempt quizzes with real-time scoring
View and analyze results instantly
Improve performance through past result tracking

For Administrators-
Create, update, and delete quizzes
Manage questions, options, and answers
Monitor student attempts and results
Analyze performance reports

Technologies Used:
Frontend: HTML5, CSS3, JavaScript
Backend (optional): Firebase / Local Storage
Tools: Visual Studio Code, GitHub Pages

Modules Overview:
User Authentication Module – Handles login and registration.
Quiz Management Module – Allows admin to manage quizzes and questions.
Quiz Participation Module – Enables students to take quizzes and view results.
Result Evaluation Module – Automatically scores and displays results.

Future Enhancements:
Integration with databases like MySQL or Firebase
Timer-based quizzes
Leaderboard and ranking system
AI-based question recommendations
